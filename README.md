# Centralized Material Logistic and Project Financial Tracking System

## Overview

The Centralized Material Logistic and Project Financial Tracking System is a web-based platform developed for E.V. Catapang Design-Construction and Supply Company. The system centralizes material logistics, project financial records, and project monitoring activities into a single platform to improve operational visibility, coordination, and decision-making.

The system helps users manage inventory, monitor project budgets and expenses, track project progress, and generate reports. It also incorporates predictive analytics to support project cost estimation and budget overrun detection.

## Key Features

- Material Inventory Monitoring
- Budget and Expense Tracking
- Project Progress Tracking
- Project Performance Monitoring
- Supplier Management
- Analytics Dashboards and Reports
- Material Demand Forecasting
- Project Cost Prediction
- Budget Overrun Classification
- Notifications and Alerts
